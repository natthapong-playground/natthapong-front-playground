# Frontend File Responsibilities

SCOPE
  TECH:  Entries cover root runtime scripts and every tracked file under
         frontend-playground/ as of 2026-07-24. Generated and installed directories
         are excluded.
  PLAIN: Every frontend file and Windows run helper committed to Git is explained
         below.

== Repository runtime helpers ==

setup.bat
  TECH:  Detects Windows architecture; downloads pinned Node.js 22.23.1 into .venv/;
         verifies the official SHA-256; installs npm 11.11.0 and its cache locally;
         scopes npm, temporary, home, and node-gyp paths locally; runs npm ci against
         frontend-playground/package-lock.json; and records the lockfile fingerprint.
  PLAIN: Sets up all Windows tools and packages inside this project without a global
         installation.

start.bat
  TECH:  Selects the architecture-specific .venv Node toolchain, runs setup.bat when
         tools or Angular CLI packages are absent or the lockfile fingerprint changed,
         scopes writable tool paths locally, and forwards optional arguments to npm
         start from frontend-playground/.
  PLAIN: Starts the development website and automatically runs setup when needed.

== Project configuration ==

frontend-playground/.editorconfig
  TECH:  Defines cross-editor defaults for indentation, line endings, charset, and
         final newlines.
  PLAIN: Keeps basic formatting consistent between contributors' editors.

frontend-playground/.gitignore
  TECH:  Excludes Angular caches, dependencies, build output, coverage, and local
         editor files from this application directory.
  PLAIN: Prevents generated and machine-specific files from entering Git.

frontend-playground/.prettierrc
  TECH:  Stores the application's Prettier formatting preferences.
  PLAIN: Tells the formatter how source code should look.

frontend-playground/Dockerfile
  TECH:  Builds the Angular application with Node 22 Alpine and serves the browser
         output from a stock Nginx Alpine image on port 80.
  PLAIN: Packages the frontend as a small web-server container.

frontend-playground/README.md
  TECH:  Provides directory-level setup, script, source-area, and backend notes and
         links to the repository README for the full guide.
  PLAIN: Gives developers a quick start when they open the Angular folder directly.

frontend-playground/angular.json
  TECH:  Configures Angular build, development server, public assets, global styles,
         size budgets, source maps, and the unit-test builder.
  PLAIN: Tells Angular how to build, run, and test the application.

frontend-playground/package.json
  TECH:  Declares npm scripts, patched Angular 21 runtime/build packages,
         Material/CDK, RxJS, TypeScript, Prettier, jsdom, and Vitest dependencies.
  PLAIN: Lists the tools and libraries required by the frontend.

frontend-playground/package-lock.json
  TECH:  Locks the full npm dependency graph for reproducible installations.
  PLAIN: Makes `npm ci` install the same package versions on each machine.

frontend-playground/tsconfig.json
  TECH:  Defines shared strict TypeScript and Angular compiler settings.
  PLAIN: Sets the main type-safety rules for the project.

frontend-playground/tsconfig.app.json
  TECH:  Extends the shared TypeScript settings for browser application sources.
  PLAIN: Controls how production application code is compiled.

frontend-playground/tsconfig.spec.json
  TECH:  Extends the shared TypeScript settings for unit-test sources.
  PLAIN: Controls how test files are compiled.
